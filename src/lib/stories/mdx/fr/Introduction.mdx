# @skywalklab/lib

La bibliothèque de composants derrière [SkywalkLab](https://skywalklab.com), une agence digitale qui crée des sites
web et des outils d'IA sur mesure — **{allComponents.length + uncatalogued_internals.length} composants exportés**
répartis en {catalog.length} catégories, chacun aussi disponible en custom element, ainsi que les modules CSS qui les
stylent et les plugins Vite sur lesquels ils s'appuient. Le site de l'agence et chaque modèle de démo sont assemblés à
partir d'eux.

Construite avec les **runes et snippets de Svelte 5** et empaquetée avec `svelte-package`.
Dépendances peer : `svelte@^5` et `@sveltejs/kit@^2.22.0`.

Sur les {allComponents.length + uncatalogued_internals.length}, **{allComponents.length}** composants ont une page de
documentation dans cette barre latérale ; les 17 autres sont exportés et utilisables, mais ce sont des éléments internes
de composants documentés, ou de longs documents juridiques.

export const SvelteMount = ({ component, props }) => {
  const ref = React.useRef(null);
  React.useEffect(() => {
    const app = mount(component, { target: ref.current, props });
    return () => unmount(app);
  }, []);
  return React.createElement("div", { ref });
};


## Utilisation

Importez depuis l'entrée racine, ou depuis le sous-chemin d'une catégorie pour garder le graphe d'imports restreint :

```svelte
<script>
  import { Header1, Footer1 } from "@skywalklab/lib/components/nav";
  import { Accordion } from "@skywalklab/lib/components/disclosure";
</script>
```

Les composants reposent sur `preflight.css`, qui supprime les styles par défaut du navigateur. Il est fourni avec le
package :

```ts
import "@skywalklab/lib/styles/preflight.css";
```

## Organisation de ce Storybook

- **Une page par composant.** Chacun a une page de documentation avec son tableau de props et ses contrôles en direct,
  et deux stories en dessous : `Default` l'affiche comme composant Svelte, et `Custom Element` affiche la même chose
  sous forme de balise HTML, avec le code à copier juste en dessous.
- **Intégration des composants Svelte.** Quatre pages de référence pour utiliser la bibliothèque dans un projet :
  [Composants](?path=/docs/component-integration-components-svelte--docs) pour les importer et les styler,
  [Modules CSS](?path=/docs/component-integration-css-modules--docs) pour les styles partagés des boutons et des
  hamburgers, [Custom elements](?path=/docs/component-integration-custom-elements--docs) pour les utiliser en dehors de
  Svelte, et [Plugins Vite](?path=/docs/component-integration-vite-plugins--docs) pour les plugins de build, qui
  n'ont pas de rendu et donc pas de stories.
- **Aperçus des composants.** La section `Overviews` a une page par catégorie qui affiche tous ses composants à la
  fois, chaque libellé renvoyant vers la page de documentation du composant.
- **Pages des modules CSS.** La section `CSS-Modules` affiche seuls les modules partagés de boutons, titres, listes
  et en-tête.
- **Styles d'exemple.** Les démos ajoutent des styles de présentation que les composants ne fournissent volontairement
  pas : ce que vous voyez ici, c'est le composant plus une mise en page autour.
